### Skill 2: Trello Project Management
**Skill ID:** trello
**Domain:** Business Automation
**Proficiency:** 2/10
**Tools:** trello-api, curl, jq, bash

**What I Learned:**
- Manage Trello boards, lists, and cards via REST API
- Create, move, and archive cards programmatically
- Add comments to cards
- List boards, lists, and cards with filters
- Automate task creation from automation scripts

**Key Commands:**
```bash
# List boards
curl -s "https://api.trello.com/1/members/me/boards?key=$TRELLO_API_KEY&token=$TRELLO_TOKEN" | jq '.[] | {name, id}'

# Create a card
curl -s -X POST "https://api.trello.com/1/cards?key=$TRELLO_API_KEY&token=$TRELLO_TOKEN" \
  -d "idList={listId}" \
  -d "name=Card Title" \
  -d "desc=Card description"

# Move a card
curl -s -X PUT "https://api.trello.com/1/cards/{cardId}?key=$TRELLO_API_KEY&token=$TRELLO_TOKEN" \
  -d "idList={newListId}"
```

**Setup Required:**
```bash
export TRELLO_API_KEY="your-api-key"
export TRELLO_TOKEN="your-token"
```

**Wealth Creation Use Cases:**
- Track client projects and deadlines
- Organize business tasks across boards
- Automate task creation from outreach scripts
- Collaborate on team workflows with clients
- Build project management system for client work
