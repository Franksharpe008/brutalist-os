### What I Learned
- Obsidian vaults are normal folders with Markdown notes
- obsidian-cli automates vault operations (create, search, move, delete)
- Obsidian tracks vaults in `~/Library/Application Support/obsidian/obsidian.json`
- Wikilinks (`[[note]]`) are automatically updated when moving notes
- obsidian-cli is already installed on this system

### Use Cases for Wealth Creation
1. **Business insights** - Store learnings from client work, market research
2. **Wealth strategies** - Document financial tactics, investment insights
3. **Content creation** - Turn notes into blog posts, emails, proposals
4. **Project knowledge** - Organize technical learnings, best practices
5. **Cross-reference** - Build knowledge graph connecting ideas (semantic memory)

### Key Commands
```bash
# Set default vault
obsidian-cli set-default "<vault-name>"

# Search notes
obsidian-cli search "query"
obsidian-cli search-content "query"

# Create note
obsidian-cli create "Folder/Note" --content "..." --open

# Safe move (updates wikilinks)
obsidian-cli move "old/path" "new/path"

# Delete
obsidian-cli delete "path/note"
```
